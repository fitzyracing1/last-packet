# Last packet

Publishable finder. Opens in the browser, pulls the newest stopped RIPE Atlas ping, and logs every find in this browser. Download writes `finds.jsonl`.

Published page: https://fitzyracing1.github.io/last-packet/

Pages source: branch `main`, folder `/` (root).

Local full mode, including this machine's socket table, is `python3 server.py` then http://127.0.0.1:8765.
